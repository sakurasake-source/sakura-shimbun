# 半月流量复盘方案（盲区3：数据回流闭环）

状态：**方案已定，未启动**。每月 1 日 / 16 日 21:00 系统通知提醒（launchd `com.sakusaku.sakuranews.review`）。
收到提醒后，对 Claude 说「开始半月流量复盘」即可执行。

## 为什么半月一次
小红书笔记流量有长尾（收藏型内容数周后仍在进曝光），发布当天的数据会严重低估。
半月窗口既能覆盖首波分发，又能看到上一期笔记的长尾表现。

## 每次复盘做什么

### 1. 取数（Playwright，复用 data/xhs_profile 持久化登录态）
- 打开 creator.xiaohongshu.com 「数据中心 → 笔记数据」
- 抓过去 15 天发布的每篇笔记：曝光、阅读、点赞、收藏、评论、涨粉
- 同时抓上一期（15-30 天前）笔记的最新累计值 → 对比上次快照算**长尾增量**
- 快照落盘 `data/analytics/YYYY-MM-DD.json`（git 跟踪，形成时间序列）

### 2. 归因（每篇打标签后交叉）
- 内容型：日报 / 单条搬运-视频 / 单条搬运-图 / 名场面 / 美图
- 标题型：问句钩子 / 感叹花痴 / 引用台词 / 新闻式
- 发布路径：私密转公开 / 草稿箱手发 / 直接公开 ← **顺便验证盲区1的降权传闻**
- 发布时段

### 3. 产出（固定三件）
1. 一张表：本期笔记 × 核心指标 × 标签
2. 三条结论：什么涨了、什么扑了、和上期比变化
3. 若有可靠发现（≥3 篇同向证据）→ 提议《风格手册》§8.5 修订，**经你确认后**才改手册

## 原则
- 只读数据，不动任何笔记
- 单篇孤例不下结论，防止过拟合
- 「私密转公开 vs 直接发」的对照数据优先积累，先解决盲区1
